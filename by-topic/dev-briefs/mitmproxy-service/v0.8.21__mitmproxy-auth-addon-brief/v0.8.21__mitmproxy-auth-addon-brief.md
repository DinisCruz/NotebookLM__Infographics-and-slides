# MitmProxy Custom Authentication Addon - Implementation Brief

**Project:** MitmProxy Multi-User Authentication System  
**Version:** v1.0.0  
**Date:** January 2026

---

## Executive Summary

This document specifies a custom authentication addon for MitmProxy that provides multi-user proxy authentication with role-based access, audit logging, and seamless integration with the existing FastAPI interceptor pipeline.

---

## Part 1: Introduction

### 1.1 Why — The Problem

The MitmProxy service currently operates as an **open proxy**, meaning anyone who knows the hostname and port can route traffic through it. This creates several critical issues:

| Problem | Risk Level | Impact |
|---------|------------|--------|
| **Unauthorized Access** | Critical | Anyone can use the proxy to access internal resources |
| **No Accountability** | High | Cannot track who performed what actions |
| **Resource Abuse** | Medium | Unlimited usage without attribution |
| **Compliance Gaps** | High | No audit trail for security reviews |
| **Multi-tenant Conflicts** | Medium | Cannot isolate users or apply per-user policies |

**Real-world scenario:** A developer shares the proxy URL with a colleague for debugging. That colleague shares it further. Soon, unknown parties are routing traffic through the proxy, potentially accessing sensitive transformation features, filling cache storage, or worse — using it as an anonymous relay.

### 1.2 How — The Solution Approach

We implement a **custom mitmproxy addon** that intercepts all incoming connections and enforces HTTP Basic Authentication before allowing traffic to flow. This approach was chosen over alternatives for specific reasons:

| Approach | Pros | Cons | Decision |
|----------|------|------|----------|
| **Built-in `--proxyauth`** | Zero code, simple | Single user OR htpasswd only, no logging, no roles | ❌ Rejected |
| **Reverse proxy (nginx)** | Battle-tested | Adds infrastructure, doesn't integrate with mitmproxy internals | ❌ Rejected |
| **Custom Addon** | Full control, logging, roles, FastAPI integration | Requires Python code | ✅ **Selected** |
| **mTLS certificates** | Very secure | Complex setup, certificate management overhead | ❌ Overkill |

**Why Custom Addon wins:**

1. **Native Integration** — Runs inside mitmproxy's event loop, zero latency overhead
2. **User Context Propagation** — Can inject `X-Proxy-User` headers for downstream FastAPI
3. **Audit Logging** — Full visibility into auth success/failure events
4. **Role-Based Behavior** — Different users can have different transformation modes
5. **Hot Reload Ready** — Can watch config file for changes without restart
6. **Future Extensibility** — Can integrate with LDAP, OAuth, database backends

### 1.3 What — The Deliverables

This implementation provides:

## Part 4: Implementation

### 4.1 Core Authentication Addon

**File:** `/home/ubuntu/proxy_auth.py`

```python
"""
MitmProxy Custom Authentication Addon
=====================================

Multi-user proxy authentication with:
- JSON-based user management
- Role-based access control
- SHA256 password hashing
- Audit logging
- Account lockout protection
- User context propagation to FastAPI

Version: 1.0.0
"""

import base64
import hashlib
import json
import os
from datetime       import datetime, timedelta
from pathlib        import Path
from typing         import Dict, Optional, Tuple
from dataclasses    import dataclass, field
from mitmproxy      import http, ctx


# ═══════════════════════════════════════════════════════════════════════════════
# Configuration
# ═══════════════════════════════════════════════════════════════════════════════

CONFIG_PATH         = Path(os.environ.get("PROXY_AUTH_CONFIG", "/etc/mitmproxy/users.json"))
AUTH_LOG_PATH       = Path(os.environ.get("PROXY_AUTH_LOG", "/var/log/mitmproxy/auth.log"))
AUTH_REALM          = os.environ.get("PROXY_AUTH_REALM", "MitmProxy")
VERSION             = "1.0.0"


# ═══════════════════════════════════════════════════════════════════════════════
# Data Classes
# ═══════════════════════════════════════════════════════════════════════════════

@dataclass
class AuthResult:
    """Result of an authentication attempt"""
    success     : bool
    username    : Optional[str] = None
    role        : Optional[str] = None
    error       : Optional[str] = None
    should_lock : bool          = False


@dataclass
class UserSession:
    """Tracks failed attempts for lockout"""
    failed_attempts : int       = 0
    locked_until    : Optional[datetime] = None
    last_attempt    : Optional[datetime] = None


# ═══════════════════════════════════════════════════════════════════════════════
# Authentication Addon
# ═══════════════════════════════════════════════════════════════════════════════

class ProxyAuthenticator:
    """
    Multi-user proxy authentication addon for mitmproxy.
    
    Features:
    - JSON-based user database with hot reload
    - SHA256 password hashing
    - Role assignment per user
    - Failed attempt tracking and lockout
    - Audit logging (success and failure)
    - User context injection for downstream services
    """
    
    def __init__(self):
        self.users: Dict[str, dict]             = {}
        self.roles: Dict[str, dict]             = {}
        self.settings: dict                     = {}
        self.sessions: Dict[str, UserSession]   = {}  # Track failed attempts by IP+username
        self.config_mtime: float                = 0   # For hot reload detection
        
        self._load_config()
    
    # ───────────────────────────────────────────────────────────────────────────
    # Configuration Loading
    # ───────────────────────────────────────────────────────────────────────────
    
    def _load_config(self) -> None:
        """Load user configuration from JSON file"""
        if not CONFIG_PATH.exists():
            ctx.log.warn(f"[AUTH] Config not found: {CONFIG_PATH}, using empty config")
            self._use_default_config()
            return
        
        try:
            current_mtime = CONFIG_PATH.stat().st_mtime
            
            # Skip reload if unchanged
            if current_mtime == self.config_mtime:
                return
            
            with open(CONFIG_PATH, 'r') as f:
                config = json.load(f)
            
            self.users    = config.get("users", {})
            self.roles    = config.get("roles", {})
            self.settings = config.get("settings", {})
            self.config_mtime = current_mtime
            
            ctx.log.info(f"[AUTH] Loaded {len(self.users)} users, {len(self.roles)} roles from {CONFIG_PATH}")
            
        except json.JSONDecodeError as e:
            ctx.log.error(f"[AUTH] Invalid JSON in {CONFIG_PATH}: {e}")
            self._use_default_config()
        except Exception as e:
            ctx.log.error(f"[AUTH] Failed to load config: {e}")
            self._use_default_config()
    
    def _use_default_config(self) -> None:
        """Fallback configuration when file is missing/invalid"""
        ctx.log.warn("[AUTH] Using default config - CREATE /etc/mitmproxy/users.json!")
        self.users = {}  # No users = all auth fails
        self.roles = {}
        self.settings = {
            "max_failed_attempts": 5,
            "lockout_duration_minutes": 15,
            "log_successful_auth": True,
            "log_failed_auth": True,
        }
    
    def _check_config_reload(self) -> None:
        """Check if config file changed and reload if needed"""
        if CONFIG_PATH.exists():
            current_mtime = CONFIG_PATH.stat().st_mtime
            if current_mtime != self.config_mtime:
                ctx.log.info("[AUTH] Config file changed, reloading...")
                self._load_config()
    
    # ───────────────────────────────────────────────────────────────────────────
    # Password Handling
    # ───────────────────────────────────────────────────────────────────────────
    
    def _hash_password(self, password: str) -> str:
        """Hash password using SHA256"""
        return hashlib.sha256(password.encode('utf-8')).hexdigest()
    
    def _verify_password(self, username: str, password: str) -> bool:
        """Verify password against stored hash"""
        user_data = self.users.get(username)
        if not user_data:
            return False
        
        # Support both hashed and plain passwords (for migration)
        stored = user_data.get("password_hash") or user_data.get("password")
        if not stored:
            return False
        
        # If stored password looks like a hash (64 hex chars), compare hashes
        if len(stored) == 64 and all(c in '0123456789abcdef' for c in stored.lower()):
            return self._hash_password(password) == stored.lower()
        else:
            # Plain password comparison (not recommended for production)
            return password == stored
    
    # ───────────────────────────────────────────────────────────────────────────
    # Lockout Management
    # ───────────────────────────────────────────────────────────────────────────
    
    def _get_session_key(self, source_ip: str, username: str) -> str:
        """Generate session key for tracking failed attempts"""
        return f"{source_ip}:{username}"
    
    def _is_locked_out(self, source_ip: str, username: str) -> bool:
        """Check if user/IP combination is locked out"""
        session_key = self._get_session_key(source_ip, username)
        session = self.sessions.get(session_key)
        
        if not session or not session.locked_until:
            return False
        
        if datetime.utcnow() > session.locked_until:
            # Lockout expired, reset
            session.locked_until = None
            session.failed_attempts = 0
            return False
        
        return True
    
    def _record_failed_attempt(self, source_ip: str, username: str) -> bool:
        """Record failed attempt, returns True if should lock"""
        session_key = self._get_session_key(source_ip, username)
        
        if session_key not in self.sessions:
            self.sessions[session_key] = UserSession()
        
        session = self.sessions[session_key]
        session.failed_attempts += 1
        session.last_attempt = datetime.utcnow()
        
        max_attempts = self.settings.get("max_failed_attempts", 5)
        
        if session.failed_attempts >= max_attempts:
            lockout_minutes = self.settings.get("lockout_duration_minutes", 15)
            session.locked_until = datetime.utcnow() + timedelta(minutes=lockout_minutes)
            return True
        
        return False
    
    def _clear_failed_attempts(self, source_ip: str, username: str) -> None:
        """Clear failed attempts on successful auth"""
        session_key = self._get_session_key(source_ip, username)
        if session_key in self.sessions:
            del self.sessions[session_key]
    
    # ───────────────────────────────────────────────────────────────────────────
    # Audit Logging
    # ───────────────────────────────────────────────────────────────────────────
    
    def _log_auth_event(self, event: str, username: str, source_ip: str, 
                        target_host: str = "", **extra) -> None:
        """Write authentication event to audit log"""
        should_log = (
            (event == "auth_success" and self.settings.get("log_successful_auth", True)) or
            (event != "auth_success" and self.settings.get("log_failed_auth", True))
        )
        
        if not should_log:
            return
        
        log_entry = {
            "timestamp"  : datetime.utcnow().isoformat() + "Z",
            "event"      : event,
            "username"   : username,
            "source_ip"  : source_ip,
            "target_host": target_host,
            **extra
        }
        
        # Log to mitmproxy console
        if event == "auth_success":
            ctx.log.info(f"[AUTH] ✓ {username}@{source_ip} -> {target_host}")
        else:
            ctx.log.warn(f"[AUTH] ✗ {username}@{source_ip}: {event}")
        
        # Write to audit log file
        try:
            AUTH_LOG_PATH.parent.mkdir(parents=True, exist_ok=True)
            with open(AUTH_LOG_PATH, 'a') as f:
                f.write(json.dumps(log_entry) + "\n")
        except Exception as e:
            ctx.log.error(f"[AUTH] Failed to write audit log: {e}")
    
    # ───────────────────────────────────────────────────────────────────────────
    # Core Authentication
    # ───────────────────────────────────────────────────────────────────────────
    
    def _parse_auth_header(self, auth_header: str) -> Tuple[Optional[str], Optional[str]]:
        """Parse Proxy-Authorization header, returns (username, password)"""
        if not auth_header:
            return None, None
        
        if not auth_header.startswith("Basic "):
            return None, None
        
        try:
            encoded = auth_header[6:]  # Remove "Basic "
            decoded = base64.b64decode(encoded).decode('utf-8')
            
            if ':' not in decoded:
                return None, None
            
            username, password = decoded.split(':', 1)
            return username.strip(), password
            
        except Exception:
            return None, None
    
    def _authenticate(self, username: str, password: str, 
                      source_ip: str, target_host: str) -> AuthResult:
        """Core authentication logic"""
        
        # Check lockout first
        if self._is_locked_out(source_ip, username):
            self._log_auth_event("auth_locked_out", username, source_ip, target_host)
            return AuthResult(success=False, error="Account temporarily locked")
        
        # Check if user exists
        if username not in self.users:
            should_lock = self._record_failed_attempt(source_ip, username)
            self._log_auth_event("auth_failure", username, source_ip, target_host, 
                                reason="invalid_username")
            return AuthResult(success=False, error="Invalid credentials", should_lock=should_lock)
        
        user_data = self.users[username]
        
        # Check if user is enabled
        if not user_data.get("enabled", True):
            self._log_auth_event("auth_failure", username, source_ip, target_host,
                                reason="account_disabled")
            return AuthResult(success=False, error="Account disabled")
        
        # Verify password
        if not self._verify_password(username, password):
            should_lock = self._record_failed_attempt(source_ip, username)
            self._log_auth_event("auth_failure", username, source_ip, target_host,
                                reason="invalid_password")
            return AuthResult(success=False, error="Invalid credentials", should_lock=should_lock)
        
        # Success!
        self._clear_failed_attempts(source_ip, username)
        role = user_data.get("role", "user")
        
        self._log_auth_event("auth_success", username, source_ip, target_host, role=role)
        
        return AuthResult(success=True, username=username, role=role)
    
    # ───────────────────────────────────────────────────────────────────────────
    # Response Helpers
    # ───────────────────────────────────────────────────────────────────────────
    
    def _send_auth_required(self, flow: http.HTTPFlow, message: str = "Proxy authentication required") -> None:
        """Send 407 Proxy Authentication Required response"""
        flow.response = http.Response.make(
            407,
            message.encode('utf-8'),
            {
                "Proxy-Authenticate": f'Basic realm="{AUTH_REALM}"',
                "Content-Type": "text/plain; charset=utf-8",
                "X-Proxy-Version": VERSION,
            }
        )
    
    def _inject_user_headers(self, flow: http.HTTPFlow, auth_result: AuthResult, source_ip: str) -> None:
        """Inject user context headers for downstream services"""
        flow.request.headers["X-Proxy-User"]      = auth_result.username
        flow.request.headers["X-Proxy-Role"]      = auth_result.role
        flow.request.headers["X-Proxy-Auth-Time"] = datetime.utcnow().isoformat() + "Z"
        flow.request.headers["X-Proxy-Source-IP"] = source_ip
    
    def _get_client_ip(self, flow: http.HTTPFlow) -> str:
        """Extract client IP from flow"""
        if flow.client_conn and flow.client_conn.peername:
            return flow.client_conn.peername[0]
        return "unknown"
    
    # ───────────────────────────────────────────────────────────────────────────
    # Mitmproxy Event Handlers
    # ───────────────────────────────────────────────────────────────────────────
    
    def http_connect(self, flow: http.HTTPFlow) -> None:
        """
        Handle CONNECT requests (HTTPS tunneling).
        This is where authentication happens for HTTPS sites.
        """
        self._handle_auth(flow)
    
    def request(self, flow: http.HTTPFlow) -> None:
        """
        Handle regular HTTP requests.
        Skip if already authenticated via CONNECT.
        """
        # Check if already authenticated in http_connect
        if getattr(flow, '_proxy_authenticated', False):
            return
        
        self._handle_auth(flow)
    
    def _handle_auth(self, flow: http.HTTPFlow) -> None:
        """Common authentication handler"""
        
        # Hot reload config if changed
        self._check_config_reload()
        
        source_ip   = self._get_client_ip(flow)
        target_host = flow.request.pretty_host
        
        # Parse auth header
        auth_header = flow.request.headers.get("Proxy-Authorization", "")
        username, password = self._parse_auth_header(auth_header)
        
        # No credentials provided
        if not username:
            self._send_auth_required(flow)
            return
        
        # Authenticate
        result = self._authenticate(username, password, source_ip, target_host)
        
        if not result.success:
            self._send_auth_required(flow, result.error or "Authentication failed")
            return
        
        # Success - inject headers and mark as authenticated
        self._inject_user_headers(flow, result, source_ip)
        flow._proxy_authenticated = True
        
        # Remove auth header before forwarding (don't leak to target)
        if "Proxy-Authorization" in flow.request.headers:
            del flow.request.headers["Proxy-Authorization"]


# ═══════════════════════════════════════════════════════════════════════════════
# Addon Registration
# ═══════════════════════════════════════════════════════════════════════════════

addons = [ProxyAuthenticator()]

print("=" * 60)
print("Proxy Authentication Addon Loaded!")
print(f"Version: {VERSION}")
print(f"Config:  {CONFIG_PATH}")
print(f"Realm:   {AUTH_REALM}")
print("=" * 60)
```

### 4.2 User Management CLI Tool

```python
#!/usr/bin/env python3
"""
MitmProxy User Management CLI
=============================

Manage users in /etc/mitmproxy/users.json

Usage:
    ./manage_users.py list
    ./manage_users.py add <username> [--role=<role>] [--description=<desc>]
    ./manage_users.py remove <username>
    ./manage_users.py disable <username>
    ./manage_users.py enable <username>
    ./manage_users.py passwd <username>
    ./manage_users.py show <username>
"""

import argparse
import getpass
import hashlib
import json
import sys
from datetime import datetime
from pathlib import Path

CONFIG_PATH = Path("/etc/mitmproxy/users.json")

def load_config():
    """Load configuration file"""
    if not CONFIG_PATH.exists():
        return {
            "$schema": "mitmproxy-users-v1",
            "version": "1.0.0",
            "updated_at": datetime.utcnow().isoformat() + "Z",
            "settings": {
                "max_failed_attempts": 5,
                "lockout_duration_minutes": 15,
                "log_successful_auth": True,
                "log_failed_auth": True,
            },
            "users": {},
            "roles": {
                "admin": {"description": "Full access", "allowed_modes": ["*"]},
                "developer": {"description": "Development access", "allowed_modes": ["off", "cache", "xxx", "hashes"]},
                "readonly": {"description": "Read-only", "allowed_modes": ["off"]},
            }
        }
    
    with open(CONFIG_PATH, 'r') as f:
        return json.load(f)

def save_config(config):
    """Save configuration file"""
    config["updated_at"] = datetime.utcnow().isoformat() + "Z"
    
    CONFIG_PATH.parent.mkdir(parents=True, exist_ok=True)
    
    with open(CONFIG_PATH, 'w') as f:
        json.dump(config, f, indent=4)
    
    # Secure permissions
    CONFIG_PATH.chmod(0o600)
    print(f"✓ Saved to {CONFIG_PATH}")

def hash_password(password):
    """Hash password with SHA256"""
    return hashlib.sha256(password.encode('utf-8')).hexdigest()

def cmd_list(args):
    """List all users"""
    config = load_config()
    users = config.get("users", {})
    
    if not users:
        print("No users configured.")
        return
    
    print(f"\n{'Username':<20} {'Role':<15} {'Enabled':<10} {'Description'}")
    print("-" * 70)
    
    for username, data in sorted(users.items()):
        role = data.get("role", "user")
        enabled = "✓" if data.get("enabled", True) else "✗"
        desc = data.get("description", "")[:30]
        print(f"{username:<20} {role:<15} {enabled:<10} {desc}")
    
    print(f"\nTotal: {len(users)} users")

def cmd_add(args):
    """Add a new user"""
    config = load_config()
    
    if args.username in config.get("users", {}):
        print(f"✗ User '{args.username}' already exists")
        sys.exit(1)
    
    # Get password
    password = getpass.getpass(f"Password for {args.username}: ")
    password_confirm = getpass.getpass("Confirm password: ")
    
    if password != password_confirm:
        print("✗ Passwords do not match")
        sys.exit(1)
    
    if len(password) < 8:
        print("✗ Password must be at least 8 characters")
        sys.exit(1)
    
    # Create user
    config.setdefault("users", {})[args.username] = {
        "password_hash": hash_password(password),
        "role": args.role,
        "enabled": True,
        "created_at": datetime.utcnow().isoformat() + "Z",
        "description": args.description or "",
    }
    
    save_config(config)
    print(f"✓ User '{args.username}' created with role '{args.role}'")

def cmd_remove(args):
    """Remove a user"""
    config = load_config()
    
    if args.username not in config.get("users", {}):
        print(f"✗ User '{args.username}' not found")
        sys.exit(1)
    
    confirm = input(f"Remove user '{args.username}'? [y/N]: ")
    if confirm.lower() != 'y':
        print("Cancelled")
        return
    
    del config["users"][args.username]
    save_config(config)
    print(f"✓ User '{args.username}' removed")

def cmd_disable(args):
    """Disable a user"""
    config = load_config()
    
    if args.username not in config.get("users", {}):
        print(f"✗ User '{args.username}' not found")
        sys.exit(1)
    
    config["users"][args.username]["enabled"] = False
    config["users"][args.username]["disabled_at"] = datetime.utcnow().isoformat() + "Z"
    
    save_config(config)
    print(f"✓ User '{args.username}' disabled")

def cmd_enable(args):
    """Enable a user"""
    config = load_config()
    
    if args.username not in config.get("users", {}):
        print(f"✗ User '{args.username}' not found")
        sys.exit(1)
    
    config["users"][args.username]["enabled"] = True
    config["users"][args.username].pop("disabled_at", None)
    
    save_config(config)
    print(f"✓ User '{args.username}' enabled")

def cmd_passwd(args):
    """Change user password"""
    config = load_config()
    
    if args.username not in config.get("users", {}):
        print(f"✗ User '{args.username}' not found")
        sys.exit(1)
    
    password = getpass.getpass(f"New password for {args.username}: ")
    password_confirm = getpass.getpass("Confirm password: ")
    
    if password != password_confirm:
        print("✗ Passwords do not match")
        sys.exit(1)
    
    if len(password) < 8:
        print("✗ Password must be at least 8 characters")
        sys.exit(1)
    
    config["users"][args.username]["password_hash"] = hash_password(password)
    
    save_config(config)
    print(f"✓ Password updated for '{args.username}'")

def cmd_show(args):
    """Show user details"""
    config = load_config()
    
    if args.username not in config.get("users", {}):
        print(f"✗ User '{args.username}' not found")
        sys.exit(1)
    
    user = config["users"][args.username]
    
    print(f"\nUser: {args.username}")
    print("-" * 40)
    for key, value in user.items():
        if key == "password_hash":
            value = value[:16] + "..." # Truncate hash
        print(f"  {key}: {value}")

def main():
    parser = argparse.ArgumentParser(description="MitmProxy User Management")
    subparsers = parser.add_subparsers(dest="command", help="Commands")
    
    # list
    subparsers.add_parser("list", help="List all users")

    add_parser = subparsers.add_parser("add", help="Add a new user")

    # remove
    remove_parser = subparsers.add_parser("remove", help="Remove a user")

    disable_parser = subparsers.add_parser("disable", help="Disable a user")
    disable_parser.add_argument("username")

    enable_parser = subparsers.add_parser("enable", help="Enable a user")
    enable_parser.add_argument("username")
    
    # passwd
    passwd_parser = subparsers.add_parser("passwd", help="Change user password")

    # show
    show_parser = subparsers.add_parser("show", help="Show user details")
    show_parser.add_argument("username")
    
    args = parser.parse_args()
    
    if not args.command:
        parser.print_help()

    commands = {
        "list": cmd_list,
        "add": cmd_add,
        "remove": cmd_remove,
        "disable": cmd_disable,
        "enable": cmd_enable,
        "passwd": cmd_passwd,

    commands[args.command](args)

if __name__ == "__main__":
    main()
```

## Part 7: Security Considerations

### 7.1 Password Storage

| Method | Security | Notes |
|--------|----------|-------|
| Plain text | ❌ Bad | Never use in production |
| SHA256 | ✓ Acceptable | Current implementation |
| bcrypt/scrypt | ✓✓ Better | Add if needed (requires extra dependency) |

### 7.2 Transport Security

The proxy itself uses HTTP Basic Auth, which transmits credentials in base64 (not encrypted). Mitigations:

1. **Use HTTPS for the proxy connection** (requires TLS termination)
2. **Restrict network access** (firewall rules, VPN only)
3. **Use strong, unique passwords** (CLI enforces 8+ chars)
