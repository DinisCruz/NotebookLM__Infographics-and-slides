## Overview

A project brief for creating a web-based HTML UI service that integrates with an existing build orchestrator to facilitate automated AWS environment setup. The service exposes AWS primitives as REST API endpoints, enabling on-demand provisioning of entire application stacks with minimal manual intervention.

The design follows a "primitives not workflows" approach where each AWS action is a dedicated endpoint, allowing the external build orchestrator to control sequencing while the UI service focuses on executing individual operations securely.

## Key Topics

- **On-Demand Environment Deployment**: Spin up/tear down entire infrastructure from scratch via UI or API call
- **Build Orchestrator Integration**: REST API endpoints called by external orchestration engine for sequenced deployment
- **AWS Primitives as APIs**: Granular endpoints for S3, AMI, EC2, Lambda, Target Groups, Auto Scaling, etc.
- **Secure Credential Handling**: Public key encryption for AWS credentials with pass-through decryption
- **OSBot-AWS Library**: Leverages OWASP Security Bot toolkit for simplified AWS operations

## API Endpoints Overview

- `/create-s3-bucket` – Create S3 buckets with configuration
- `/check-s3-bucket` – Verify bucket existence/accessibility
- `/create-ami` – Create Amazon Machine Images
- `/launch-ami-instance` – Launch EC2 instances from AMIs
- `/create-target-group` – Set up load balancer target groups
- `/create-auto-scaling-group` – Create ASGs with target group attachment
- `/create-lambda-function` – Deploy Lambda functions with Function URLs

## Architecture Highlights

- **Stateless Service Design**: No complex state tracking; orchestrator or AWS queries track resource state
- **Primitive Operations with Verification**: Each create action has corresponding check endpoint
- **Multiple Deployment Modes**: Fresh deployment vs update, secure mode vs dev mode
- **Web UI for Visibility**: Dashboard for manual control, real-time progress, and debugging
