## What is Html_MGraph?

**Html_MGraph is a multi-graph architecture that transforms HTML documents into interconnected, specialized graphs—enabling powerful manipulation, analysis, and perfect round-trip reconstruction.** Instead of representing HTML as a single cluttered graph, it separates concerns into 5 purpose-specific graphs that share node identities, allowing you to work with exactly the aspects you need.

Think of it like a database normalization for HTML: the DOM structure, attributes, scripts, and styles each live in their own optimized graph, yet they're all linked by shared `Node_Id` values that enable seamless recombination.

### The Problem It Solves

Traditional HTML-to-graph approaches create a single graph with everything mixed together:

```
┌─────────────────────────────────────────────────────────────────┐
│                    SINGLE GRAPH (Traditional)                    │
├─────────────────────────────────────────────────────────────────┤
│  Element Node ──► Tag Node ("div")                              │
│       │                                                          │
│       ├──► Attr Node (class="main")                              │
│       ├──► Attr Node (id="app")                                  │
│       ├──► Child Element ──► Tag Node ──► Attr Nodes...         │
│       └──► Text Node ("Hello")                                   │
│                                                                  │
│  Problems:                                                       │
│  • Visualization cluttered with tag/attr noise                   │
│  • Transformations must carefully preserve metadata              │
│  • <head> and <body> in same traversal space                    │
│  • Round-trip reconstruction complex                             │
└─────────────────────────────────────────────────────────────────┘
```

**With Html_MGraph's multi-graph architecture:**

```
┌─────────────────────────────────────────────────────────────────┐
│                    MULTI-GRAPH ARCHITECTURE                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────────┐  │
│  │ body_graph  │  │ head_graph  │  │    attrs_graph          │  │
│  │             │  │             │  │                         │  │
│  │ Pure DOM    │  │ Pure DOM    │  │  Tags + Attributes      │  │
│  │ structure   │  │ structure   │  │  for ALL elements       │  │
│  │ + text only │  │ + text only │  │                         │  │
│  └─────────────┘  └─────────────┘  └─────────────────────────┘  │
│                                                                  │
│  ┌─────────────────────────┐  ┌─────────────────────────────┐   │
│  │    scripts_graph        │  │     styles_graph            │   │
│  │                         │  │                             │   │
│  │  JavaScript content     │  │  CSS content                │   │
│  │  from <script> tags     │  │  from <style>/<link> tags   │   │
│  └─────────────────────────┘  └─────────────────────────────┘   │
│                                                                  │
│  Shared Node_IDs enable cross-graph lookups                     │
└─────────────────────────────────────────────────────────────────┘
```

### Design Philosophy

1. **Separation of concerns** — Each graph has a focused responsibility. Work with structure without attribute noise.
2. **Shared identity** — Same `Node_Id` used across graphs enables instant cross-graph lookups.
3. **Perfect round-trip** — HTML → Graphs → HTML preserves everything, including attribute order and boolean attributes.
4. **Query what you need** — Want just the body structure? Query `body_graph`. Need element's class? Query `attrs_graph`.
5. **Type-safe foundation** — Built on MGraph-DB with full runtime type checking via OSBot-Utils Type_Safe.

### The Power of Multi-Graph Architecture

#### 1. Clean Visualization

```python
# Visualize ONLY the DOM structure - no tag/attribute clutter
dot_output = html_mgraph.to_dot(graph='body')  # Clean tree of elements + text
```

#### 2. Targeted Queries

```python
# Get tag for any element (queries attrs_graph internally)
tag = html_mgraph.get_tag(node_id)  # "div"

# Get all attributes (ordered, preserves round-trip)
attrs = html_mgraph.get_attributes(node_id)  # {"class": "main", "id": "app"}

# Find all elements with a specific tag
divs = html_mgraph.document.get_elements_by_tag('div')  # [Node_Id, Node_Id, ...]
```

#### 3. Script/Style Separation

```python
# Get all inline scripts
scripts = html_mgraph.scripts_graph.get_inline_scripts()

# Get JavaScript content for a specific <script> element
js_code = html_mgraph.get_script_content(script_node_id)

# Get CSS content for a <style> element
css_code = html_mgraph.get_style_content(style_node_id)
```

#### 4. Perfect Round-Trip

```python
# Parse HTML into multi-graph
html_mgraph = Html_MGraph.from_html(original_html)

# ... perform transformations ...

# Reconstruct HTML with full fidelity
reconstructed = html_mgraph.to_html()

# Boolean attributes, attribute order, whitespace - all preserved
assert reconstructed == original_html  # ✓
```

#### 5. Cross-Graph Lookups via Shared Node_Id

```python
# Same Node_Id works across all graphs
node_id = some_element_id

# In body_graph: get children
children = html_mgraph.body_graph.get_element_children(node_id)

# In attrs_graph: get tag and attributes
tag = html_mgraph.attrs_graph.get_tag(node_id)
attrs = html_mgraph.attrs_graph.get_attributes(node_id)

# In scripts_graph: get script content (if it's a <script>)
content = html_mgraph.scripts_graph.get_script_content(node_id)
```

## Quick Start

### Basic Usage

```python
from mgraph_ai_service_html_graph.service.html_mgraph.Html_MGraph import Html_MGraph

# Parse HTML into multi-graph structure
html = """
<html lang="en">
  <head>
    <title>My Page</title>
    <style>.main { color: blue; }</style>
  </head>
  <body class="container">
    <div id="app">
      Hello <b>World</b>
    </div>
    <script>console.log('init');</script>
  </body>
</html>
"""

html_mgraph = Html_MGraph.from_html(html)

# Export back to HTML (perfect round-trip)
html_output = html_mgraph.to_html()

# Export to Dict format
html_dict = html_mgraph.to_html_dict()

# Export to DOT for visualization
dot_string = html_mgraph.to_dot(graph='body')  # Options: 'all', 'head', 'body', 'attrs', 'scripts', 'styles'
```

### Querying Elements

```python
# Get the root node IDs
html_root = html_mgraph.root_id()          # <html> element
head_root = html_mgraph.head_root_id()     # <head> element  
body_root = html_mgraph.body_root_id()     # <body> element

# Get tag name for any element
tag = html_mgraph.get_tag(node_id)         # "div", "p", "span", etc.

# Get all attributes
attrs = html_mgraph.get_attributes(node_id)  # {"class": "main", "id": "app"}

# Get specific attribute
class_val = html_mgraph.get_attribute(node_id, 'class')  # "main"

# Get text content
text = html_mgraph.get_text_content(node_id)  # "Hello World"

# Get script/style content
js = html_mgraph.get_script_content(script_node_id)
css = html_mgraph.get_style_content(style_node_id)
```

### Walking the Tree

```python
# Get direct children of <head>
head_children = html_mgraph.get_head_children()

# Get direct children of <body>
body_children = html_mgraph.get_body_children()

# Walk entire body tree (returns list of element info dicts)
for element_info in html_mgraph.walk_body():
    print(f"{element_info['tag']}: {element_info['attributes']}")

# Walk entire head tree
for element_info in html_mgraph.walk_head():
    print(f"{element_info['tag']}: {element_info['attributes']}")
```

### Accessing Component Graphs Directly

```python
# Direct graph access for advanced operations
body_graph    = html_mgraph.body_graph      # Html_MGraph__Body
head_graph    = html_mgraph.head_graph      # Html_MGraph__Head
attrs_graph   = html_mgraph.attrs_graph     # Html_MGraph__Attributes
scripts_graph = html_mgraph.scripts_graph   # Html_MGraph__Scripts
styles_graph  = html_mgraph.styles_graph    # Html_MGraph__Styles

# Example: Get all element nodes in body
all_body_elements = body_graph.all_element_nodes()

# Example: Get all text nodes in body
all_body_text = body_graph.all_text_nodes()

# Example: Find all elements with a specific tag
all_divs = attrs_graph.get_elements_by_tag('div')

# Example: Get all inline scripts
inline_scripts = scripts_graph.get_inline_scripts()
```

### Getting Statistics

```python
# Comprehensive statistics across all graphs
stats = html_mgraph.stats()

print(f"Head: {stats.head.element_nodes} elements, {stats.head.text_nodes} text nodes")
print(f"Body: {stats.body.element_nodes} elements, {stats.body.text_nodes} text nodes")
print(f"Attributes: {stats.attributes.registered_elements} elements, {stats.attributes.total_attributes} attrs")
print(f"Scripts: {stats.scripts.inline_scripts} inline, {stats.scripts.external_scripts} external")
print(f"Styles: {stats.styles.inline_styles} inline, {stats.styles.external_styles} external")
```

## Architecture Overview

### The 5+1 Graph System

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        Html_MGraph__Document                            │
│                        (Orchestrator Graph)                             │
│                                                                         │
│   root_id: <html> element                                               │
│                                                                         │
│   References to:                                                        │
│   ├── head_graph    → Html_MGraph__Head                                │
│   ├── body_graph    → Html_MGraph__Body                                │
│   ├── attrs_graph   → Html_MGraph__Attributes                          │
│   ├── scripts_graph → Html_MGraph__Scripts                             │
│   └── styles_graph  → Html_MGraph__Styles                              │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### Graph Responsibilities

| Graph | Purpose | Contains |
|-------|---------|----------|
| **Html_MGraph__Document** | Orchestrator | References to all other graphs, `<html>` element |
| **Html_MGraph__Head** | Document metadata | `<head>` structure + text (title content, etc.) |
| **Html_MGraph__Body** | Visible content | `<body>` structure + text nodes |
| **Html_MGraph__Attributes** | Element properties | Tag names + attributes for ALL elements |
| **Html_MGraph__Scripts** | JavaScript | `<script>` elements and their content |
| **Html_MGraph__Styles** | CSS | `<style>` elements and `<link>` references |

### Shared Node_Id Pattern

**Critical Design Principle**: Element nodes use the **same `Node_Id`** across all relevant graphs.

```
┌─────────────────────────────────────────────────────────────────┐
│                 SHARED NODE_ID PATTERN                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  HTML: <div class="main" id="content">Hello</div>               │
│                                                                  │
│  Node_Id = "abc123" appears in:                                 │
│                                                                  │
│  body_graph:           attrs_graph:                              │
│  ┌─────────────┐      ┌─────────────────────────────────────┐   │
│  │ abc123      │      │ abc123 (under tag:div)              │   │
│  │ path: div   │      │   ├── class → "main"                │   │
│  │ children:[] │      │   └── id → "content"                │   │
│  └─────────────┘      └─────────────────────────────────────┘   │
│        │                                                         │
│        └── text node: "Hello"                                   │
│                                                                  │
│  Round-trip reconstruction:                                      │
│  1. Get element from body_graph (structure)                     │
│  2. Lookup tag by Node_Id in attrs_graph → "div"               │
│  3. Lookup attrs by Node_Id in attrs_graph → {class, id}       │
│  4. Reconstruct: <div class="main" id="content">               │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### Three-Node Attribute Model

Attributes use a sophisticated model for deduplication and ordering:

```
┌─────────────────────────────────────────────────────────────────┐
│               ATTRIBUTE STORAGE (THREE-NODE MODEL)               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  element_node ──[attr]──► instance_node ──[name]──► name_node   │
│                    │           (position)     │         │        │
│                    │                          │      "class"     │
│                    │                          │     (shared)     │
│                    │                          │                  │
│                    │                          └─[value]─► "main" │
│                    │                                    (shared) │
│                    │                                             │
│                    └──[attr]──► instance_node ──[name]──► "id"  │
│                                     (position)           (shared)│
│                                          │                       │
│                                          └─[value]─► "content"   │
│                                                                  │
│  Benefits:                                                       │
│  • Position preserved for round-trip                            │
│  • Name nodes shared across elements (dedup "class", "id", etc.)│
│  • Value nodes shared across elements (dedup common values)     │
│  • Boolean attributes: no value node (required, disabled, etc.) │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## Graph-Specific APIs

### Html_MGraph__Body / Html_MGraph__Head

Both share the same API for DOM structure:

```python
# Constants
graph.PREDICATE_CHILD  # Edge predicate for child elements
graph.PREDICATE_TEXT   # Edge predicate for text content

# Building (used during conversion)
graph.create_element(node_path, node_id=None)  # Create element node
graph.create_text(text, parent_id, position)   # Create text node
graph.add_child(parent_id, child_id, position) # Link parent → child
graph.set_root(node_id)                        # Set root element

# Querying
graph.get_element_children(node_id)  # Get child elements in order
graph.get_text_nodes(node_id)        # Get text nodes in order
graph.get_text_content(node_id)      # Get concatenated text
graph.is_text_node(node_id)          # Check if text node
graph.is_element_node(node_id)       # Check if element node

# Iteration
graph.all_element_nodes()  # Get all element Node_Ids
graph.all_text_nodes()     # Get all text Node_Ids
```

### Html_MGraph__Attributes

```python
# Building
graph.register_element(node_id, tag)                    # Register element with tag
graph.add_attribute(node_id, attr_name, attr_value, position)  # Add attribute

# Tag Queries
graph.get_tag(node_id)               # Get tag name for element → "div"
graph.get_elements_by_tag(tag)       # Get all elements with tag → [Node_Id, ...]
graph.get_all_tags()                 # Get all unique tags → ["div", "p", "span"]

# Attribute Queries
graph.get_attributes(node_id)        # Get all attrs → {"class": "main", "id": None}
graph.get_attribute(node_id, name)   # Get specific attr → "main"
graph.get_elements_with_attribute(attr_name, attr_value=None)  # Find by attr
```

### Html_MGraph__Scripts

```python
# Building
graph.register_script(node_id, content=None)  # Register script (content=None for external)

# Querying
graph.get_script_content(node_id)    # Get JS content → "console.log('hi')"
graph.is_inline_script(node_id)      # Has inline content?
graph.is_external_script(node_id)    # External (no content)?
graph.get_all_scripts()              # All scripts in order
graph.get_inline_scripts()           # Only inline scripts
graph.get_external_scripts()         # Only external scripts
```

### Html_MGraph__Styles

```python
# Building
graph.register_style(node_id, content=None)   # Register <style>
graph.register_link(node_id)                   # Register <link rel="stylesheet">

# Querying
graph.get_style_content(node_id)     # Get CSS content
graph.is_inline_style(node_id)       # Has inline content?
graph.is_external_style(node_id)     # External stylesheet?
graph.get_all_styles()               # All styles in order
graph.get_inline_styles()            # Only inline styles
graph.get_external_styles()          # Only external stylesheets
```

## Conversion Pipeline

### Forward: HTML → Graphs

```
HTML String
    │
    ▼
Html__To__Html_Dict (osbot_utils)
    │
    ▼
Html_Dict (OSBot format: {tag, attrs, nodes: [...]})
    │
    ▼
Html__To__Html_MGraph__Document
    │
    ├──► Create Document with root_id = <html>
    ├──► Extract <head> → Html_MGraph__Head
    ├──► Extract <body> → Html_MGraph__Body
    ├──► Extract all tags/attrs → Html_MGraph__Attributes
    ├──► Extract script content → Html_MGraph__Scripts
    └──► Extract style content → Html_MGraph__Styles
    │
    ▼
Html_MGraph__Document (containing all 5 graphs)
```

### Reverse: Graphs → HTML

```
Html_MGraph__Document
    │
    ▼
Html_MGraph__Document__To__Html_Dict
    │
    ├──► Walk body_graph for structure
    ├──► Lookup tags via attrs_graph
    ├──► Lookup attributes via attrs_graph
    ├──► Get script content via scripts_graph
    └──► Get style content via styles_graph
    │
    ▼
Html_Dict (OSBot format)
    │
    ▼
Html_Dict__To__Html (osbot_utils)
    │
    ▼
HTML String (round-trip complete!)
```

## Common Patterns

### Pattern 1: Find Elements by Tag and Check Attributes

```python
html_mgraph = Html_MGraph.from_html(html)

# Find all divs with a specific class
divs = html_mgraph.attrs_graph.get_elements_by_tag('div')
for div_id in divs:
    attrs = html_mgraph.get_attributes(div_id)
    if attrs.get('class') == 'container':
        # Process this div
        text = html_mgraph.body_graph.get_text_content(div_id)
        children = html_mgraph.body_graph.get_element_children(div_id)
```

### Pattern 2: Extract All Text Content

```python
html_mgraph = Html_MGraph.from_html(html)

# Get all text from body
all_text = []
for text_node_id in html_mgraph.body_graph.all_text_nodes():
    text = html_mgraph.body_graph.node_value(text_node_id)
    if text:
        all_text.append(text)

full_text = ' '.join(all_text)
```

### Pattern 3: Analyze Script Usage

```python
html_mgraph = Html_MGraph.from_html(html)

# Count inline vs external scripts
stats = html_mgraph.scripts_graph.stats()
print(f"Inline: {stats.inline_scripts}, External: {stats.external_scripts}")

# Get all inline script content
for script_id in html_mgraph.scripts_graph.get_inline_scripts():
    content = html_mgraph.get_script_content(script_id)
    print(f"Script {script_id}: {len(content)} chars")
```

### Pattern 4: Build Element Info Report

```python
html_mgraph = Html_MGraph.from_html(html)

# Get comprehensive info for each body element
for node_id in html_mgraph.body_graph.all_element_nodes():
    info = html_mgraph.document.element_info(node_id)
    print(f"<{info['tag']}> attrs={info['attributes']}")
    
    if info['tag'] == 'script' and 'script_content' in info:
        print(f"  JS: {info['script_content'][:50]}...")
```

### Pattern 5: Round-Trip with Validation

```python
original_html = "<html><body><input required class='x'></body></html>"

# Convert to graph
html_mgraph = Html_MGraph.from_html(original_html)

# Convert back
reconstructed = html_mgraph.to_html()

# Validate round-trip
assert 'required' in reconstructed      # Boolean attr preserved
assert 'class="x"' in reconstructed     # Regular attr preserved
```

## Best Practices

### DO: Use the Facade for Simple Operations

```python
# ✅ Good - use Html_MGraph facade methods
tag = html_mgraph.get_tag(node_id)
attrs = html_mgraph.get_attributes(node_id)
text = html_mgraph.get_text_content(node_id)
```

### DO: Access Component Graphs for Bulk Operations

```python
# ✅ Good - direct graph access for iteration
for element_id in html_mgraph.body_graph.all_element_nodes():
    # Process each element
    pass
```

### DO: Check Graph Roots Before Iteration

```python
# ✅ Good - verify graph has content
if html_mgraph.body_graph.root_id:
    children = html_mgraph.get_body_children()
```

### DON'T: Assume Element Exists in All Graphs

```python
# ❌ Bad - not all elements have scripts
content = html_mgraph.scripts_graph.get_script_content(any_node_id)

# ✅ Good - check tag first
if html_mgraph.get_tag(node_id) == 'script':
    content = html_mgraph.get_script_content(node_id)
```

### DON'T: Modify Graphs Directly (Use Converters)

```python
# ❌ Bad - direct modification breaks consistency
html_mgraph.body_graph.create_element(path, node_id)

# ✅ Good - create new Html_MGraph from modified HTML
modified_html = modify_html_string(original_html)
new_mgraph = Html_MGraph.from_html(modified_html)
```

### DON'T: Rely on Node_Id String Format

```python
# ❌ Bad - Node_Id format is opaque
if str(node_id).startswith('abc'):
    pass

# ✅ Good - use graph methods to identify nodes
if html_mgraph.get_tag(node_id) == 'div':
    pass
```

## Troubleshooting

### Problem: get_tag() Returns None

**Cause**: Node_Id not registered in attrs_graph

```python
# Check if element exists
if html_mgraph.attrs_graph.get_tag(node_id) is None:
    # Node might be a text node, not an element
    if html_mgraph.body_graph.is_text_node(node_id):
        print("This is a text node, not an element")
```

### Problem: Round-Trip HTML Different

**Cause**: Whitespace normalization or HTML parser differences

```python
# The round-trip preserves structure and attributes
# but may normalize whitespace

# Original:    <div   class="x" >
# Round-trip:  <div class="x">
# Both are semantically identical
```

### Problem: Script Content is None

**Cause**: External script (has src attribute, no inline content)

```python
if html_mgraph.scripts_graph.is_external_script(node_id):
    # Get src from attributes instead
    src = html_mgraph.get_attribute(node_id, 'src')
else:
    content = html_mgraph.get_script_content(node_id)
```

### Problem: Attributes Missing Order

**Cause**: Using dict iteration instead of get_attributes()

```python
# ✅ get_attributes() preserves insertion order
attrs = html_mgraph.get_attributes(node_id)
for name, value in attrs.items():  # Order preserved
    print(f"{name}={value}")
```

### Problem: Statistics Show Zero Elements

**Cause**: Graph not properly initialized

```python
# Ensure from_html() was called
html_mgraph = Html_MGraph.from_html(html)  # Creates all graphs

# Not this (leaves graphs empty):
html_mgraph = Html_MGraph()  # Empty!
```

## Summary Checklist

When working with Html_MGraph:

**Basic Usage:**
- [ ] Use `Html_MGraph.from_html(html_string)` to parse HTML
- [ ] Use `html_mgraph.to_html()` for round-trip back to HTML
- [ ] Use `html_mgraph.to_dot(graph='body')` for visualization

**Querying:**
- [ ] Use facade methods for single-element queries: `get_tag()`, `get_attributes()`, `get_text_content()`
- [ ] Use component graphs for bulk operations: `body_graph.all_element_nodes()`
- [ ] Check `get_tag()` result before assuming element type

**Understanding the Graphs:**
