## 1. Executive Summary

The **IFD Snapshot Generator** is a Python service that programmatically extracts all dependencies from an IFD minor version's HTML entry points and creates a self-contained snapshot. This enables clean consolidation from scattered minor versions to major versions.

**Key Outputs:**
- `manifest.json` - Complete dependency mapping with load order
- `content.txt` - Formatted text dump with tree structure and all file contents
- `snapshot.zip` - In-memory zip with all files (optional)
- Extracted folder - Physical folder with snapshot contents (optional)

**Key Principle**: This is a **programmatic transformation** leveraging Html_MGraph's multi-graph architecture for dependency extraction.

## 2. Problem Statement

### The IFD Surgical Override Pattern

In IFD development, files are scattered across version folders due to surgical overrides:

```
v0.2/
├── v0.2.0/
│   ├── css/common.css                    (base - 200 lines)
│   └── js/services/api-client.js         (base - 500 lines)
├── v0.2.3/
│   └── js/services/api-client.js         (surgical - 15 lines)
├── v0.2.5/
│   └── js/services/api-client.js         (surgical - 20 lines)
├── v0.2.9/
│   └── js/services/api-client.js         (surgical - 10 lines)
└── v0.2.10/
    ├── css/server-reload.css             (new file)
    └── playground.html                    (entry point)
```

The HTML entry point (`playground.html`) references these scattered files:

```html
<link rel="stylesheet" href="../v0.2.0/css/common.css">
<link rel="stylesheet" href="../v0.2.10/css/server-reload.css">
<script src="../v0.2.0/js/services/api-client.js"></script>
<script src="../v0.2.3/js/services/api-client.js"></script>
<script src="../v0.2.5/js/services/api-client.js"></script>
<script src="../v0.2.9/js/services/api-client.js"></script>
```

### The Problem

When consolidating to v0.3.0, developers need:
1. A clear manifest of what files are actually used
2. All relevant files in one place
3. Load order preserved exactly
4. Provenance tracked for each file

### The Solution

The IFD Snapshot Generator:
1. Parses HTML entry points using **Html_MGraph** multi-graph architecture
2. Extracts external CSS/JS dependencies via `scripts_graph` and `styles_graph`
3. Groups dependencies into load chains by logical name
4. Generates manifest, content dump, and optional zip/folder

### Leveraging Html_MGraph Multi-Graph Architecture

The key insight is that **Html_MGraph already separates scripts and styles into dedicated graphs**:

```python
html_mgraph = Html_MGraph.from_html(html_content)

# scripts_graph knows ALL <script> elements
for script_id in html_mgraph.scripts_graph.get_all_scripts():
    if html_mgraph.scripts_graph.is_external_script(script_id):
        src = html_mgraph.get_attribute(script_id, 'src')      # "../v0.2.0/js/api-client.js"

# styles_graph knows ALL <style> and <link rel="stylesheet"> elements
for style_id in html_mgraph.styles_graph.get_all_styles():
    if html_mgraph.styles_graph.is_external_style(style_id):
        href = html_mgraph.get_attribute(style_id, 'href')     # "../v0.2.0/css/common.css"
```

This is **far cleaner** than manually parsing HTML for `<script>` and `<link>` tags.

### 6.1 IFD_Dependency_Extractor

**File**: `IFD_Dependency_Extractor.py`

```python
# ═══════════════════════════════════════════════════════════════════════════════
# IFD Dependency Extractor - Extract dependencies using Html_MGraph
# Leverages Html_MGraph's scripts_graph and styles_graph for clean extraction
# ═══════════════════════════════════════════════════════════════════════════════

import re
from typing                                                                      import List
from osbot_utils.type_safe.Type_Safe                                             import Type_Safe
from osbot_utils.type_safe.type_safe_core.decorators.type_safe                   import type_safe
from osbot_utils.type_safe.primitives.core.Safe_Str                              import Safe_Str
from osbot_utils.type_safe.primitives.domains.files.safe_str.Safe_Str__File__Path import Safe_Str__File__Path
from osbot_utils.utils.Files                                                     import path_combine, folder_name
from mgraph_ai_service_html_graph.service.html_mgraph.Html_MGraph                import Html_MGraph
from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Schema__IFD_Dependency import Schema__IFD_Dependency
from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Safe_Types__IFD   import Safe_Str__IFD_Version
from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Safe_Types__IFD   import Safe_Str__IFD_Logical_Name
from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Safe_Types__IFD   import Safe_Str__IFD_Resource_Type
from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Safe_Types__IFD   import Safe_Str__IFD_File_Type
from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Safe_Types__IFD   import Safe_UInt__IFD_Load_Order


VERSION_PATTERN = re.compile(r'v\d+\.\d+\.?\d*')                                 # Matches v0.2.0, v0.2.10, v1.0, etc.


class IFD_Dependency_Extractor(Type_Safe):                                       # Extract deps from HTML using Html_MGraph
    seen_logical_names : dict                                                    # Track first occurrence per logical_name

    # ═══════════════════════════════════════════════════════════════════════════
    # Main Extraction Method
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def extract_from_html(self                                     ,             # Extract all external dependencies
                          html_content : Safe_Str                  ,             # Raw HTML content
                          html_path    : Safe_Str__File__Path      ,             # Path to HTML file
                          base_path    : Safe_Str__File__Path                    # Base path for resolution
                     ) -> List[Schema__IFD_Dependency]:
        html_mgraph       = Html_MGraph.from_html(html_content)
        dependencies      = []
        load_order        = Safe_UInt__IFD_Load_Order(0)

        css_deps = self.extract_css_dependencies(html_mgraph, html_path, base_path, load_order)
        dependencies.extend(css_deps)
        load_order = Safe_UInt__IFD_Load_Order(len(css_deps))

        js_deps = self.extract_js_dependencies(html_mgraph, html_path, base_path, load_order)
        dependencies.extend(js_deps)

        return dependencies

    # ═══════════════════════════════════════════════════════════════════════════
    # CSS Extraction
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def extract_css_dependencies(self                              ,             # Extract external stylesheets
                                 html_mgraph : Html_MGraph         ,
                                 html_path   : Safe_Str__File__Path,
                                 base_path   : Safe_Str__File__Path,
                                 start_order : Safe_UInt__IFD_Load_Order
                            ) -> List[Schema__IFD_Dependency]:
        dependencies = []
        load_order   = start_order

        for style_id in html_mgraph.styles_graph.get_all_styles():
            if html_mgraph.styles_graph.is_external_style(style_id):
                href = html_mgraph.get_attribute(style_id, 'href')
                if href:
                    dep = self.create_dependency(original_path  = href                              ,
                                                 html_path      = html_path                         ,
                                                 base_path      = base_path                         ,
                                                 resource_type  = Safe_Str__IFD_Resource_Type('css'),
                                                 load_order     = load_order                        )
                    if dep:
                        dependencies.append(dep)
                        load_order = Safe_UInt__IFD_Load_Order(load_order + 1)

        return dependencies

    # ═══════════════════════════════════════════════════════════════════════════
    # JS Extraction
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def extract_js_dependencies(self                               ,             # Extract external scripts
                                html_mgraph : Html_MGraph          ,
                                html_path   : Safe_Str__File__Path ,
                                base_path   : Safe_Str__File__Path ,
                                start_order : Safe_UInt__IFD_Load_Order
                           ) -> List[Schema__IFD_Dependency]:
        dependencies = []
        load_order   = start_order

        for script_id in html_mgraph.scripts_graph.get_all_scripts():
            if html_mgraph.scripts_graph.is_external_script(script_id):
                src = html_mgraph.get_attribute(script_id, 'src')
                if src:
                    dep = self.create_dependency(original_path  = src                              ,
                                                 html_path      = html_path                        ,
                                                 base_path      = base_path                        ,
                                                 resource_type  = Safe_Str__IFD_Resource_Type('js'),
                                                 load_order     = load_order                       )
                    if dep:
                        dependencies.append(dep)
                        load_order = Safe_UInt__IFD_Load_Order(load_order + 1)

        return dependencies

    # ═══════════════════════════════════════════════════════════════════════════
    # Dependency Creation
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def create_dependency(self                                     ,             # Create dependency from path
                          original_path : Safe_Str                 ,
                          html_path     : Safe_Str__File__Path     ,
                          base_path     : Safe_Str__File__Path     ,
                          resource_type : Safe_Str__IFD_Resource_Type,
                          load_order    : Safe_UInt__IFD_Load_Order
                     ) -> Schema__IFD_Dependency:
        resolved     = self.resolve_path(original_path, html_path, base_path)
        version      = self.extract_version(original_path)
        logical_name = self.extract_logical_name(original_path)
        file_type    = self.classify_file_type(logical_name)

        return Schema__IFD_Dependency(original_path  = Safe_Str__File__Path(original_path),
                                      resolved_path  = resolved                           ,
                                      source_version = version                            ,
                                      resource_type  = resource_type                      ,
                                      file_type      = file_type                          ,
                                      logical_name   = logical_name                       ,
                                      load_order     = load_order                         )

    # ═══════════════════════════════════════════════════════════════════════════
    # Path Resolution
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def resolve_path(self                                          ,             # Resolve relative path to absolute
                     original_path : Safe_Str                      ,
                     html_path     : Safe_Str__File__Path          ,
                     base_path     : Safe_Str__File__Path
                ) -> Safe_Str__File__Path:
        html_folder = folder_name(html_path)                                     # Get folder containing HTML
        if html_folder:
            combined = path_combine(base_path, html_folder, original_path)
        else:
            combined = path_combine(base_path, original_path)

        # Normalize path (resolve ../ segments)
        import os
        normalized = os.path.normpath(combined)
        return Safe_Str__File__Path(normalized)

    # ═══════════════════════════════════════════════════════════════════════════
    # Version Extraction
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def extract_version(self, path: Safe_Str) -> Safe_Str__IFD_Version:          # Extract vN.N.N from path
        match = VERSION_PATTERN.search(path)
        if match:
            return Safe_Str__IFD_Version(match.group())
        return Safe_Str__IFD_Version('')

    # ═══════════════════════════════════════════════════════════════════════════
    # Logical Name Extraction
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def extract_logical_name(self, path: Safe_Str) -> Safe_Str__IFD_Logical_Name:  # Extract logical name
        # Remove version prefix: "../v0.2.0/js/api-client.js" -> "js/api-client"
        # Remove extension and normalize

        path_str = str(path)

        # Remove leading ../ or ./
        while path_str.startswith('../') or path_str.startswith('./'):
            path_str = path_str[3:] if path_str.startswith('../') else path_str[2:]

        # Remove version segment (v0.2.0/, v1.0/, etc.)
        match = VERSION_PATTERN.search(path_str)
        if match:
            version_end = match.end()
            if version_end < len(path_str) and path_str[version_end] == '/':
                path_str = path_str[version_end + 1:]

        # Remove file extension
        if '.' in path_str:
            path_str = path_str.rsplit('.', 1)[0]

        return Safe_Str__IFD_Logical_Name(path_str)

    # ═══════════════════════════════════════════════════════════════════════════
    # File Type Classification
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def classify_file_type(self                                    ,             # Classify as base or surgical
                           logical_name: Safe_Str__IFD_Logical_Name
                      ) -> Safe_Str__IFD_File_Type:
        logical_key = str(logical_name)

        if logical_key not in self.seen_logical_names:
            self.seen_logical_names[logical_key] = True
            return Safe_Str__IFD_File_Type('base')                               # First occurrence is base

        return Safe_Str__IFD_File_Type('surgical')                               # Subsequent are surgical

    # ═══════════════════════════════════════════════════════════════════════════
    # Reset State
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def reset(self) -> 'IFD_Dependency_Extractor':                               # Reset seen_logical_names for new extraction
        self.seen_logical_names = {}
        return self
```

```python
# ═══════════════════════════════════════════════════════════════════════════════
# IFD Snapshot Builder - Build snapshot outputs (manifest, text, zip, folder)
# ═══════════════════════════════════════════════════════════════════════════════

from typing                                                                      import List
from osbot_utils.type_safe.Type_Safe                                             import Type_Safe

class IFD_Snapshot_Builder(Type_Safe):                                           # Build snapshot outputs

    # ═══════════════════════════════════════════════════════════════════════════
    # Load Chain Building
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def build_load_chains(self                                     ,             # Group dependencies into load chains
                          dependencies: List[Schema__IFD_Dependency]
                     ) -> List[Schema__IFD_Load_Chain]:
        chains_by_name = {}                                                      # Dict[logical_name, List[deps]]

        for dep in dependencies:
            key = str(dep.logical_name)
            if key not in chains_by_name:
                chains_by_name[key] = []
            chains_by_name[key].append(dep)

        load_chains = []
        for logical_name, deps in chains_by_name.items():
            sorted_deps = sorted(deps, key=lambda d: (str(d.source_version), d.load_order))  # Sort by version then order
            chain       = Schema__IFD_Load_Chain(logical_name  = deps[0].logical_name ,
                                                 resource_type = deps[0].resource_type,
                                                 files         = sorted_deps          )
            load_chains.append(chain)

        return load_chains

    # ═══════════════════════════════════════════════════════════════════════════
    # Manifest Building
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def build_manifest(self                                        ,             # Build complete manifest
                       config       : Schema__IFD_Snapshot_Config  ,
                       html_entries : List[Schema__IFD_Html_Entry] ,
                       load_chains  : List[Schema__IFD_Load_Chain]
                  ) -> Schema__IFD_Manifest:
        versions_used = self.collect_versions(load_chains)
        file_count    = self.count_unique_files(load_chains)
        snapshot_ver  = Safe_Str__IFD_Version(f"{config.target_version}__snapshot")

        return Schema__IFD_Manifest(snapshot_version    = snapshot_ver  ,
                                    source_version      = config.target_version,
                                    html_entry_points   = html_entries  ,
                                    load_chains         = load_chains   ,
                                    versions_referenced = versions_used ,
                                    file_count          = file_count    )

    @type_safe
    def collect_versions(self                                      ,             # Collect all unique versions
                         load_chains: List[Schema__IFD_Load_Chain]
                    ) -> List[Safe_Str__IFD_Version]:
        versions = set()
        for chain in load_chains:
            for dep in chain.files:
                if dep.source_version:
                    versions.add(str(dep.source_version))

        return [Safe_Str__IFD_Version(v) for v in sorted(versions)]

    @type_safe
    def count_unique_files(self                                    ,             # Count unique files
                           load_chains: List[Schema__IFD_Load_Chain]
                      ) -> Safe_UInt:
        unique_paths = set()
        for chain in load_chains:
            for dep in chain.files:
                unique_paths.add(str(dep.resolved_path))
        return Safe_UInt(len(unique_paths))

    # ═══════════════════════════════════════════════════════════════════════════
    # Content Text Building
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def build_content_text(self                                    ,             # Build formatted text dump
                           manifest: Schema__IFD_Manifest
                      ) -> Safe_Str:
        lines = []

        # Header
        lines.append('# ═══════════════════════════════════════════════════════════════════════════════')
        lines.append('# IFD Snapshot Content Dump')
        lines.append(f'# Version: {manifest.snapshot_version}')
        lines.append(f'# Created: {manifest.created_at}')
        lines.append('# ═══════════════════════════════════════════════════════════════════════════════')
        lines.append('')

        # HTML Entry Points
        lines.append('## HTML Entry Points')
        for entry in manifest.html_entry_points:
            lines.append(f'- {entry.file_name}')
        lines.append('')

        # Versions Referenced
        lines.append('## Versions Referenced')
        lines.append(', '.join(str(v) for v in manifest.versions_referenced))
        lines.append('')

        # File Tree
        lines.append('## File Tree')
        tree_text = self.build_tree_structure(manifest)
        lines.append(tree_text)
        lines.append('')

        # File Contents
        lines.append('## Files')
        lines.append('')

        for chain in manifest.load_chains:
            for dep in chain.files:
                lines.append('# ═══════════════════════════════════════════════════════════════════════════════')
                lines.append(f'### {dep.source_version}/{dep.logical_name}.{dep.resource_type}')
                lines.append('# ═══════════════════════════════════════════════════════════════════════════════')
                lines.append('')

                content = file_contents(dep.resolved_path)
                if content:
                    lines.append(content)
                else:
                    lines.append(f'# ERROR: Could not read file: {dep.resolved_path}')

                lines.append('')

        return Safe_Str('\n'.join(lines))

    # ═══════════════════════════════════════════════════════════════════════════
    # Tree Structure Building
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def build_tree_structure(self                                  ,             # Build ASCII tree of all files
                             manifest: Schema__IFD_Manifest
                        ) -> Safe_Str:
        lines = []
        lines.append('snapshot/')
        lines.append('├── manifest.json')
        lines.append('├── content.txt')

        # HTML folder
        lines.append('├── html/')
        html_count = len(manifest.html_entry_points)
        for i, entry in enumerate(manifest.html_entry_points):
            prefix = '│   └── ' if i == html_count - 1 else '│   ├── '
            lines.append(f'{prefix}{entry.file_name}')

        # Source folder - group by version
        lines.append('└── src/')

        versions_files = {}                                                      # version -> list of relative paths
        for chain in manifest.load_chains:
            for dep in chain.files:
                version = str(dep.source_version)
                if version not in versions_files:
                    versions_files[version] = []
                rel_path = f"{dep.logical_name}.{dep.resource_type}"
                versions_files[version].append(rel_path)

        sorted_versions = sorted(versions_files.keys())
        version_count   = len(sorted_versions)

        for vi, version in enumerate(sorted_versions):
            is_last_version = (vi == version_count - 1)
            v_prefix = '    └── ' if is_last_version else '    ├── '
            lines.append(f'{v_prefix}{version}/')

            files        = sorted(versions_files[version])
            files_count  = len(files)
            inner_prefix = '        ' if is_last_version else '    │   '

            for fi, file_path in enumerate(files):
                is_last_file = (fi == files_count - 1)
                f_prefix     = '└── ' if is_last_file else '├── '
                lines.append(f'{inner_prefix}{f_prefix}{file_path}')

        return Safe_Str('\n'.join(lines))

    # ═══════════════════════════════════════════════════════════════════════════
    # Zip Building
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def build_zip_bytes(self                                       ,             # Build in-memory zip
                        manifest : Schema__IFD_Manifest            ,
                        content  : Safe_Str
                   ) -> bytes:
        with Temp_Zip_In_Memory() as zip_mem:
            # Add manifest and content
            manifest_json = json_dumps(manifest.json())
            zip_mem.add_file_from_content('manifest.json', manifest_json)
            zip_mem.add_file_from_content('content.txt'  , str(content) )

            # Add HTML entry points
            for entry in manifest.html_entry_points:
                target = f'html/{entry.file_name}'
                zip_mem.add_file_from_content(target, str(entry.html_content))

            # Add source files
            for chain in manifest.load_chains:
                for dep in chain.files:
                    file_content = file_contents(dep.resolved_path)
                    if file_content:
                        target = f'src/{dep.source_version}/{dep.logical_name}.{dep.resource_type}'
                        zip_mem.add_file_from_content(target, file_content)

            return zip_mem.zip_bytes()

    # ═══════════════════════════════════════════════════════════════════════════
    # Folder Extraction
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def extract_to_folder(self                                     ,             # Extract snapshot to folder
                          manifest    : Schema__IFD_Manifest       ,
                          content     : Safe_Str                   ,
                          output_path : Safe_Str__File__Path
                     ) -> bool:
        import os

        # Create base folder
        folder_create(output_path)

        # Write manifest
        manifest_path = os.path.join(output_path, 'manifest.json')
        file_create(manifest_path, json_dumps(manifest.json()))

        # Write content
        content_path = os.path.join(output_path, 'content.txt')
        file_create(content_path, str(content))

        # Write HTML files
        html_folder = os.path.join(output_path, 'html')
        folder_create(html_folder)
        for entry in manifest.html_entry_points:
            html_path = os.path.join(html_folder, str(entry.file_name))
            file_create(html_path, str(entry.html_content))

        # Write source files
        src_folder = os.path.join(output_path, 'src')
        folder_create(src_folder)
        for chain in manifest.load_chains:
            for dep in chain.files:
                file_content = file_contents(dep.resolved_path)
                if file_content:
                    target_dir  = os.path.join(src_folder, str(dep.source_version), os.path.dirname(str(dep.logical_name)))
                    target_file = os.path.join(src_folder, str(dep.source_version), f'{dep.logical_name}.{dep.resource_type}')
                    folder_create(target_dir)
                    file_create(target_file, file_content)

        return True
```

```python
# ═══════════════════════════════════════════════════════════════════════════════
# IFD Snapshot - Main facade for snapshot generation
# Entry point for generating IFD snapshots from HTML entry points
# ═══════════════════════════════════════════════════════════════════════════════

import os
from typing                                                                      import List
from osbot_utils.type_safe.Type_Safe                                             import Type_Safe
from osbot_utils.type_safe.type_safe_core.decorators.type_safe                   import type_safe
from osbot_utils.type_safe.primitives.core.Safe_Str                              import Safe_Str

from osbot_utils.utils.Files                                                     import file_contents, folder_files
from mgraph_ai_service_html_graph.service.ifd_snapshot.IFD_Dependency_Extractor  import IFD_Dependency_Extractor

from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Schema__IFD_Snapshot_Config import Schema__IFD_Snapshot_Config
from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Schema__IFD_Snapshot_Result import Schema__IFD_Snapshot_Result

from mgraph_ai_service_html_graph.service.ifd_snapshot.schemas.Schema__IFD_Dependency      import Schema__IFD_Dependency


class IFD_Snapshot(Type_Safe):                                                   # Main entry point for snapshot generation
    config    : Schema__IFD_Snapshot_Config                                      # Configuration
    extractor : IFD_Dependency_Extractor                                         # Dependency extraction
    builder   : IFD_Snapshot_Builder                                             # Output building

    # ═══════════════════════════════════════════════════════════════════════════
    # Main Generation Methods
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def generate(self) -> Schema__IFD_Snapshot_Result:                           # Generate complete snapshot
        self.extractor.reset()                                                   # Reset state for fresh extraction

        html_entries = self.discover_html_files()
        all_deps     = []

        for entry in html_entries:
            deps = self.extractor.extract_from_html(html_content = Safe_Str(entry.html_content),
                                                    html_path    = entry.file_path             ,
                                                    base_path    = self.config.version_root    )
            entry.dependencies = deps
            all_deps.extend(deps)

        load_chains  = self.builder.build_load_chains(all_deps)
        manifest     = self.builder.build_manifest(self.config, html_entries, load_chains)
        content_text = self.builder.build_content_text(manifest)

        return Schema__IFD_Snapshot_Result(manifest     = manifest    ,
                                           content_text = content_text)

    @type_safe
    def generate_with_zip(self) -> Schema__IFD_Snapshot_Result:                  # Generate with zip bytes
        result           = self.generate()
        result.zip_bytes = self.builder.build_zip_bytes(result.manifest, result.content_text)
        return result

    @type_safe
    def generate_to_folder(self                                    ,             # Generate and extract to folder
                           output_path: Safe_Str__File__Path
                      ) -> Schema__IFD_Snapshot_Result:
        result = self.generate()
        self.builder.extract_to_folder(result.manifest    ,
                                       result.content_text,
                                       output_path        )
        return result

    # ═══════════════════════════════════════════════════════════════════════════
    # HTML Discovery
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def discover_html_files(self) -> List[Schema__IFD_Html_Entry]:               # Find all HTML files to process
        html_entries = []
        target_path  = os.path.join(str(self.config.version_root), str(self.config.target_version))

        # Get folders to search (default: root of target version only)
        search_folders = self.config.html_folders
        if not search_folders:
            search_folders = [Safe_Str__File__Path('')]                          # Root only

        for folder in search_folders:
            search_path = os.path.join(target_path, str(folder)) if folder else target_path
            if os.path.exists(search_path):
                for file_name in os.listdir(search_path):
                    if file_name.endswith('.html'):
                        full_path    = os.path.join(search_path, file_name)
                        html_content = file_contents(full_path)

                        entry = Schema__IFD_Html_Entry(file_name    = Safe_Str__File__Path(file_name),
                                                       file_path    = Safe_Str__File__Path(full_path),
                                                       html_content = Safe_Str(html_content or '')   ,
                                                       dependencies = []                             )
                        html_entries.append(entry)

        return html_entries

    # ═══════════════════════════════════════════════════════════════════════════
    # REST API Convenience Methods
    # ═══════════════════════════════════════════════════════════════════════════

    @type_safe
    def manifest_dict(self) -> dict:                                             # Return manifest as dict (for REST API)
        result = self.generate()
        return result.manifest.json()

    @type_safe
    def content_text(self) -> Safe_Str:                                          # Return content text only
        result = self.generate()
        return result.content_text

    @type_safe
    def zip_bytes(self) -> bytes:                                                # Return zip bytes only
        result = self.generate_with_zip()
        return result.zip_bytes
```

## 8. Implementation Details

### 8.1 Key Html_MGraph Methods Used

```python
# Parse HTML into multi-graph
html_mgraph = Html_MGraph.from_html(html_content)

# Get all script elements (inline + external)
all_scripts = html_mgraph.scripts_graph.get_all_scripts()

# Check if script is external (has src attribute)
is_external = html_mgraph.scripts_graph.is_external_script(script_id)

# Get attribute value
src = html_mgraph.get_attribute(script_id, 'src')

# Same pattern for styles
all_styles  = html_mgraph.styles_graph.get_all_styles()
is_external = html_mgraph.styles_graph.is_external_style(style_id)
href        = html_mgraph.get_attribute(style_id, 'href')
```

### 8.2 Version Pattern Matching

```python
VERSION_PATTERN = re.compile(r'v\d+\.\d+\.?\d*')

# Matches:
# - v0.2.0
# - v0.2.10
# - v1.0
# - v12.345.6789

# Examples:
# "../v0.2.0/css/common.css"  -> "v0.2.0"
# "/v0/v0.2/v0.2.3/js/app.js" -> "v0.2.3" (last match)
```

### 8.3 Logical Name Extraction

```python
# Input: "../v0.2.0/js/services/api-client.js"
# Steps:
#   1. Remove "../"          -> "v0.2.0/js/services/api-client.js"
#   2. Remove version "v0.2.0/" -> "js/services/api-client.js"
#   3. Remove extension      -> "js/services/api-client"
# Output: "js/services/api-client"
```

### 8.4 File Type Classification

The first occurrence of a `logical_name` is classified as `base`, all subsequent occurrences are `surgical`:

```python
# Load order in HTML:
# 1. ../v0.2.0/js/api-client.js  -> base (first occurrence)
# 2. ../v0.2.3/js/api-client.js  -> surgical
# 3. ../v0.2.5/js/api-client.js  -> surgical
# 4. ../v0.2.9/js/api-client.js  -> surgical
```
