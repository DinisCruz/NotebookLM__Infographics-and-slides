## Overview

White paper analyzing how Europe can leverage the decline of complexity-as-a-moat to foster a new wave of tech competition. ## Key Topics

- **Complexity Moats**: How tech giants used intricate closed ecosystems as defensive barriers

- **EU Data Act**: Cloud switching mandates and data portability requirements
- **Open Banking (PSD2)**: Successful example of regulation dismantling complexity barriers
- **Modular Competition**: Startups targeting narrow segments with focused excellence
