## Overview

White paper analyzing the shift from bloated mega-applications to hyper-focused software, using Adobe Photoshop/Illustrator as a case study. The document explores how 80% of features are rarely used, how incumbents exploit lock-in for rent extraction, and how AI-assisted development enables small teams to build specialized alternatives that deliver the 10% users actually need.

## Key Topics

- **Feature Bloat Problem**: 80% of features rarely/never used, 12% generate 80% of usage
- **Incumbent Lock-in**: Proprietary formats (PSD), subscription models, price exploitation
- **Security Attack Surface**: More code = more risk, unused features still exploitable
- **Unbundling Strategy**: Targeting underserved subsets of functionality
- **AI-Enabled Development**: Small teams (5-10 people) rivaling what took 100
- **Open Source Importance**: Avoiding new lock-in through transparency and community
